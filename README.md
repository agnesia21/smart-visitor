##  Tentang Project

**Smart Visitor AI Agent** adalah sistem manajemen kunjungan berbasis web yang dirancang untuk membantu proses pencatatan dan pengelolaan data pengunjung.

Sistem ini memanfaatkan **Google Gemini** sebagai AI Agent untuk membantu proses interaksi dengan pengunjung dan mengarahkan proses pengisian informasi kunjungan.

---

##  Fitur Utama

-  **Check-in Pengunjung**
-  **Check-out Pengunjung**
-  **Pengelolaan Status Kartu**
-  **Laporan Kunjungan**
-  **Dashboard Staff**
-  **Notifikasi Staff**
-  **AI Agent dengan Google Gemini**
-  **Login dan Pengelolaan Akun Staff**
